# Installation

Use a PSP with supported custom firmware and a Sunshine-compatible host configured for H.264. Connect the PSP to a compatible 2.4 GHz access point.

1. Copy the release's `Moonlight` folder into `ms0:/PSP/GAME/`.
2. Keep `EBOOT.PBP` and `moonlight_me_helper.prx` from the same package together.
3. Start Moonlight from the PSP Games menu, connect Wi-Fi and pair with the host using the displayed PIN.
4. Select a preset and an application from the host's game list.

Pairing identity, settings and writable caches/logs use `ms0:/PSP/SAVEDATA/Moonlight/`.

v1.5 uses Sony hardware AVC decoding. Keep the application and helper from the same package together. New installations start with the Balanced preset; upgrades retain your saved settings.
